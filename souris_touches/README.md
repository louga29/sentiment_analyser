# Souris -> touches

Remplace les touches `n , . : ! ?` et Verr. Maj par les boutons de la souris (Windows).

## Utilisation

- Bouton du milieu (3e bouton) : `n` (avec Maj : `N`)
- 4e bouton (bouton latéral "précédent") :
  - clic simple : `,`
  - maintenir + molette : choisir entre `,` `.` `:` `!` `?` `Verr. Maj` (affiché près du curseur), relâcher pour taper

## Installation

1. Installer AutoHotkey v2 : https://www.autohotkey.com
2. Double-cliquer sur `souris_touches.ahk`
3. Pour le lancer au démarrage : `Win + R`, taper `shell:startup`, y placer un raccourci vers le fichier

Pour obtenir un `.exe` autonome : clic droit sur le fichier > "Compile Script".
Pour quitter : clic droit sur l'icône "H" dans la barre des tâches > Exit.
